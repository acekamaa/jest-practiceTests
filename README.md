# JavaScript Practice

A small JavaScript practice repository with implementations and Jest tests for common string, array, and calculator exercises.

## Exercises

- `calculate(a, b, operation)` — performs addition, subtraction, division, or multiplication (`src/calc.js`).
- `capitalizeChar(str)` — capitalizes the first character of a string (`src/capitalChar.js`).
- `reverseStr(str)` — returns a string with its characters in reverse order (`src/reverseStr.js`).
- `caesarCipher(string, shiftFactor)` — shifts letters while preserving case and leaving other characters unchanged (`src/caesarCipher.js`).
- `analyzeArray(arrayOfNumbers)` — returns the average, minimum, maximum, and length (`src/analyzeArray.js`).

Each exercise has a corresponding test file in `tests/`.

## Getting started

Install the development dependencies:

```sh
npm install
```

Run the test suite:

```sh
npm test
```
